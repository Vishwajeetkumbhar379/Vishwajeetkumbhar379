#### How I build with AI

- **Rules decide, AI refines.** Where money or compliance is involved, code makes the call; the model explains, drafts and adds judgement.
- **Structured output.** Models return JSON against a schema through tool use, and the code checks it (quotes must exist, scores are clamped).
- **Agents that run on their own.** Scheduled jobs that search, score and report, with a human approving anything that leaves.
- **MCP and Skills.** Connecting Claude to custom tools and teaching it repeatable workflows.
- **Measured.** Tests on every repo, and evals where accuracy matters.
